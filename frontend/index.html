ℹ️ Sobre o Projeto

O AgroInteligente é um sistema de apoio à decisão agrícola que integra quatro pilares de Inteligência Artificial:

  • Agente Inteligente — percebe o ambiente (talhão), raciocina com as demais técnicas e age recomendando irrigação, alertas e produtividade esperada.
  • Sistema Especialista — regras SE/ENTÃO sobre irrigação, estresse hídrico e risco de pragas.
  • Lógica Fuzzy — trata a gradação entre solo seco/ideal/encharcado e temperatura fria/amena/quente.
  • Machine Learning — Árvore de Decisão, KNN, K-Means, Regressão Linear e Apriori aplicados a um dataset sintético de talhões.

Projeto desenvolvido para a disciplina de Inteligência Artificial — Trabalho V1.
